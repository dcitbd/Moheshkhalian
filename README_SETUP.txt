১. আপলোড:
   এই ZIP ফাইলের ভেতরের সব ফাইল (index.html, admin.html, api.php, .htaccess, manifest.json, sw.js, data/, assets/) আপনার cPanel-এর `public_html` (বা সাবডোমেইন ফোল্ডার)-এ আপলোড ও Extract করুন।

   `data/` এবং `assets/uploads/` ফোল্ডারের পারমিশন `755` (অথবা প্রয়োজনে `775`) রাখুন যাতে ছবি আপলোড ও ডাটাবেস সেভ হয়।
   প্রয়োজনীয় PHP ভার্সন: PHP 7.0+ (PDO SQLite এক্সটেনশন চালু থাকতে হবে, যা cPanel-এ ডিফল্টভাবে চালু থাকে)।
